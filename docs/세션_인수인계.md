## 1. 꼭 지킬 규칙 (사용자 요청)

- **금지 글자**: 공백을 다 지운 글에서 "야" 바로 뒤에 하 · 해 · 했 · 합 · 할 · 한 · 함이 오면 안 됨 → ㅎ을 ㄷ으로 ("해야 되는데"). "아" 바로 뒤 "다"도 안 됨 (예: 돌-아-다니다 → 다른 말로). 코드 · 문서 · **답장 모두**. 자동 점검이 코드 · 문서는 잡아 줌
- **버전 관리**: 글 · 코드를 고치면 버전을 올림. 문서는 머리에 "문서 버전", 앱은 `node tools/bump-version.js X.Y.Z` + 인수인계 변경 기록 한 줄
- **아이 실명**을 공개 자료 · 저장소에 쓰지 않음 ("토끼를 좋아하는 딸")
- 다른 프로젝트의 첨부 파일은 쓰지 않음
- 맞장구만 치지 말고, 별로인 생각은 이유와 함께 솔직하게
- 아이에게 하는 말은 존댓말(해요체), 이름은 "우리 {name},". 극장 캐릭터끼리는 반말 가능
- 화면은 세로 기준
- 일을 마치면: 커밋 → 그 세션 브랜치에 푸시 → PR → **main 에 합치기까지** (사용자가 늘 원함). 커밋 · PR 끝 문구는 세션이 알려 주는 것 그대로. 모델 이름은 커밋 · PR 에 쓰지 않음
- 키 · 비밀번호는 대화창에 받지 않음 (환경 비밀값으로)

## 2. 저장소 한눈에

```
core/                 공통 엔진 (저장 · 번역 · 습관 · 알 · 펫 · 클럽 · 부모 확인 · 소리 · 목소리 · 익명 숫자 …)  → core/README.md
characters/sparkle    반짝이 (Let's Brush 주인공)      characters/tokkiyou  토끼유 (스튜디오 마스코트, 그림 아직 없음)
apps/lets-brush/      Let's Brush (양치 앱) v0.53.0     → apps/lets-brush/docs/개발_인수인계.md
docs/                 스튜디오 문서: 스튜디오_구조 · 시장_언어_가격 · 명예의_전당_구상 · 새앱_하루일과_기획 · 이 문서
tools/                build-site · bump-version · sync-files · lang(번역) · voice(AI 음성) · stats-worker(익명 숫자 서버)
tests/                자동 점검 (run.js · theater-check.js)
```

- 자동 점검: `node tests/run.js` (약 4분, 고친 뒤 늘). 극장 전체: `PAR=10 node tests/theater-check.js` (약 8분)
- 파일을 더하면 `node tools/sync-files.js`, 번역 점검 `node tools/lang.js`
- 시험용 앱 보기: 주소 끝 `?test=1` (지금 testParam:true 로 풀어 둠, 출시 전 false)

## 4. 최근에 바뀐 것 (v0.51 ~ v0.53)

- 극장: 이야기 120편 + 명절 8편 + 아침 한 컷 60개, 좋아요 ♡ (좋아한 이야기 4번에 1번 다시), 대사가 목소리 끝날 때까지 기다림, 말하는 사람마다 높낮이
- AI 음성 준비: 음성 파일이 있으면 그 파일, 없으면 폰 목소리. 이름 자리 (세균 7종 · 펫 기본 이름 · 아이 이름은 부모님 녹음이 있으면 부르고 없으면 안 부름)
- 언어: 일본어는 `apps/lets-brush/lang/ja.json` (언어 하나 = 파일 하나), 처음 여는 기기는 기기 언어로
- 익명 숫자 (부모님이 켠 경우만, 서버 주소 비어 있어 꺼짐) · 안 쓰는 코드 정리
- 양치 뒤 **마무리 정리 화면** (퉤 → 헹구기 → 칫솔 씻기 → 제자리) 뒤에 극장

## 5. 크레딧 아끼기

- 주제가 바뀌면 새 세션 (긴 대화는 한 번 답할 때마다 무거워짐)
- 큰 파일은 필요한 부분만 읽기, 화면 사진은 꼭 필요할 때만
- 긴 작업(극장 전체 점검 · 음성 만들기)은 배경으로 돌리고 결과 숫자만 확인
