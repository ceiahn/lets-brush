# 토끼유 스튜디오 코드 구조

문서 버전: v1.2 (2026-10-29, 문서 목록에 세션 인수인계 · 새 앱 기획)

토끼유 스튜디오의 여러 앱(양치 Let's Brush, 앞으로 배변 · 일과표 등)이 **공통 엔진 하나를 같이 쓰는** 구조예요.

```
core/                  공통 엔진 (모든 앱)          → core/README.md
characters/            캐릭터 (쓰는 앱만)
  tokkiyou/            🐰 토끼유: 스튜디오 마스코트 (디자인 준비 중)
  sparkle/             🦷 반짝이: Let's Brush 주인공
apps/<앱>/             앱 하나 (화면 · 앱 코드 · 문구 · 아이콘 · 약관 · 스토어 포장 · 앱 문서)
docs/                  스튜디오 공통 문서 (이 문서 · 시장 · 명예의 전당 구상)
tests/                 자동 점검 (지금은 lets-brush 기준)
tools/                 build-site.js · sync-files.js · bump-version.js
```

## 1. 파일을 읽는 순서

- 모듈(import) 없이 보통 `<script>` 여러 개예요. 모든 파일이 이름 공간 하나를 같이 써요. 파일로 바로 열어도(file://) 동작해요.
- **파일 이름 앞 번호 = 읽는 순서**예요. core · 앱 · 캐릭터 파일이 번호 순서대로 섞여서 읽혀요. 같은 번호면 이름순이에요.
  - 예: `00-base`(core) → `00-club`(core) → `00-config`(앱) → `01-store`(core) → `02-lang`(앱 문구) → `02-strings`(core 문구) → `02-text`(core 번역 엔진) …
- 앞 파일이 뒤 파일 것을 **읽는 순간 바로** 부르면 안 돼요. 단추 누를 때처럼 나중에 부르는 건 괜찮아요.
- 앱의 `index.html`은 공통 파일을 `../../core/js/…`로 불러요. 목록은 손으로 쓰지 말고 **`node tools/sync-files.js <앱>`** 으로 맞춰요. `sw.js` 저장 목록도 같이 맞춰 줘요.

## 2. core 와 앱의 약속

core 는 앱이 아래 이름들을 만들어 두었다고 믿고 써요. 새 앱은 이것부터 만들면 돼요.

| 앱이 만들 것 | 쓰는 곳 | 메모 |
| --- | --- | --- |
| `RES` · `CONFIG` (`js/00-config.js`) | 어디서나 | `CONFIG.subs` · `CONFIG.play` · `contact` · `webBlock` · `storeUrl` · `firstGiftStars` · `parentGate` · `testMode` · `testParam` … |
| `PACK_KO` · `PACK_EN` · `PACK_CATALOG` (`js/02-lang.js`) | 번역 엔진 | 공통 문구는 core `02-strings.js` 가 밑에 깔아 줌. 같은 키를 앱에 쓰면 앱 글이 이김. 한 · 영 말고 다른 언어는 `apps/<앱>/lang/<code>.json` (아래 7장) |
| `setLang(code)` | 받는 언어팩 | 언어팩을 받은 뒤 화면을 다시 그림 |
| `CONFIG.statsUrl` · `CONFIG.statsApp` · `#statsRow` · `#statsTgl` (없어도 됨) | 익명 숫자 (core `24-stats.js`) | 주소가 비면 아무것도 안 보내고 설정 칸도 숨김 |
| `EVENTS` (`js/03-events.js`, 없어도 됨) | 명절 엔진 | `HOLIDAYS` + 앱의 옷 · 효과. 없으면 `HOLIDAYS` 그대로 |
| `TEST_MODE` (`js/04-state.js`) | 클럽 · 웹 막기 · 개발자 메뉴 | |
| `renderPets()` · `bookPet(펫)` · `refreshHome()` · `renderSettings()` | 펫 엔진 · 클럽 화면 | 화면 모양은 앱마다 달라서 앱이 만듦 |
| HTML 조각: `#gate` · `#subIntro` · `#subCard` · `#kidPick` · `#kidChip` · `#webGate` · `#modal` · `#toast` | 부모 확인 · 클럽 · 아이 여럿 · 웹 막기 · 대화창 | 지금은 Let's Brush `index.html` 에서 복사해 가요 (다음에 core 가 직접 만들도록 바꿀 예정) |

## 3. 습관 1번 = 보상

```
습관을 마침 (양치 끝 · 손 씻기 끝 · 일과 하나 끝)
  → Habit.done()        core 04-habit: 기록 · 오늘 몇 번 · 연속 기록 · 지킴이 방석
  → petAdvance()        core 14-eggs: 펫이 자라고 알이 따뜻해짐 · 부화
  → (하루 두 번) giftPet() · checkTeams()
  → 앱이 정하는 보상     별 계산(computeRewards) · 지도 한 칸 · 극장 · 완료 화면
Habit.stamp()           부모님 칭찬 도장 (주간 기록에 표시)
```

- 별(`stars`) · 양치한 날(`log`) · 주간 기록(`log2`) · 방석(`shields` · `covered`) · 펫(`pet`)은 core 가 저장해요. 저장 이름은 예전 그대로라 기존 기록이 그대로 읽혀요.
- 아직 앱에 남은 보상: 도감(세균 · 대장 세균이 있어서), 모험 지도(반짝이 변신 옷이 있어서), 펫 방 · 동물 집. 두 번째 앱을 만들 때 공통으로 쓸 부분이 보이면 그때 core 로 올려요.

## 4. 새 앱 만들기 (순서)

1. `apps/<새 앱>/` 만들기: `index.html`(Let's Brush 에서 공통 HTML 조각 복사) · `js/00-config.js` · `js/02-lang.js` · `js/04-state.js` · `css/` · `icons/` · `manifest.json` · `sw.js` · `privacy.html` · `terms.html`
2. 캐릭터를 쓰면 `index.html` 에 `../../characters/<이름>/js/…` 한 줄
3. `node tools/sync-files.js <새 앱>` → `<script>` · `sw.js` 목록 자동
4. `node tools/build-site.js <새 앱>` → `dist/` 확인
5. Cloudflare Pages 에 프로젝트 하나 더 (빌드 명령만 앱 이름을 바꿔서), Play Console 에 앱 하나 더 (패키지 이름 · 상품 ID 따로)
6. 자동 점검(tests)을 새 앱에도 돌게 늘리기

## 5. 버전

- 앱마다 버전이 따로예요: `node tools/bump-version.js 0.50.0 lets-brush`
- core 를 고치면 그 core 를 쓰는 앱들의 버전을 올리고, 앱 인수인계 문서 변경 기록에 적어요.
- 문서는 머리에 "문서 버전"을 두고 고칠 때마다 올려요.

## 7. 언어 늘리기 (4개 이상)

- 한국어 · 영어는 앱 코드 안 (`js/02-lang.js` + 이야기 파일 `addText`). **그 밖의 언어는 언어 하나 = 파일 하나**: `apps/<앱>/lang/<code>.json`
  - 앱은 그 언어를 고른 기기만 받아 가요 (앱 크기가 언어 수만큼 커지지 않음). 처음 여는 기기는 기기 언어 팩이 있으면 저절로 받아요.
  - 빠진 글은 영어로 나와서, 일부만 번역해도 앱이 깨지지 않아요.
- 순서:
  1. `node tools/lang.js todo es --name Español --tts es-ES` → `lang-work/es.todo.json` (번역할 것만, 영어 원문 + 한국어 참고)
  2. 각 항목 `tr` 칸 채우기 (번역가 · 번역 도구 · Claude). `{pet}` · `{n}` 같은 자리표시는 그대로
  3. `node tools/lang.js merge es` → `lang/es.json` 생성 · version 올림 · `PACK_CATALOG` 에 한 줄 추가
  4. `node tools/sync-files.js` (sw 저장 목록) → `node tools/lang.js` 로 빠진 글 확인 → 자동 점검
- 번역 양 (Let's Brush v0.52.0 기준, 한 언어): 약 2,000줄 (앱 790 · 공통 140 · 극장 820 · 펫 이름 250 · 아이템 70)
- 고친 번역을 기기에 반영: 파일의 `meta.version` 과 `PACK_CATALOG` version 을 같이 올림 (`merge` 가 해 줌). 자동 점검이 둘이 다르면 잡아 줘요.
- 글꼴: 한국어(주아) · 일본어(코스기 마루)는 `core/fonts`. 라틴 악센트 · 중국어 · 태국어 등은 글꼴을 더해서 팩 `meta.font` 에 적어요. 오른쪽에서 쓰는 언어(아랍어 등)는 지금은 안 함.
