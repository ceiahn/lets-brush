# 새 앱 기획: 방과 후 하루 일과 (가칭 "토끼유 하루")

문서 버전: v1.0 (2026-10-29)
상태: **기획만** (코드 없음). 새 세션에서 아래 "7. 만드는 순서" 1단계부터 시작

## 0. 한눈에

- **문제**: 아이가 학교에서 돌아오면 날마다 할 일이 있어요 (가방 정리 · TV · 양치 · 이틀에 한 번 목욕 · 탕목욕 놀이 · 그림 그리기 · 학습지). 습관이 잘 안 잡히고, 부모가 날마다 하나하나 말해 주기가 힘들어요.
- **목표**: 부모가 말하지 않아도 **아이가 화면을 보고 스스로** 차례대로 해 나가게. 부모는 처음에 한 번 정해 두고, 저녁에 확인만.
- **방법**: 그림 일과표 + 토끼유가 말로 알려 주기 + 하나 끝낼 때마다 작은 보상. "할 일 먼저, TV는 그다음" 같은 순서를 앱이 지켜 줌.
- 토끼유 스튜디오 두 번째 앱. Let's Brush 를 만들며 만든 공통 엔진(`core/`)을 그대로 씀.

## 1. 누가 · 언제

- 아이: 어린이집 · 유치원 · 초등 저학년 (대략 5~9세). 글을 다 못 읽어도 쓸 수 있게 **그림 + 목소리**가 기본
- 때: 방과 후 집에 와서 잘 때까지 (시간대는 부모가 정함). 아침 등원 준비 일과는 나중에 같은 구조로 더함
- 기기: 집에 두는 폰 · 태블릿 (현관이나 거실). 아이가 앱을 열고 → 카드를 보고 → **화면을 끄고 일을 하고** → 다시 와서 "다 했어요"

## 2. 지킬 원칙 (아이 일과표에서 널리 쓰는 방법)

| 원칙 | 앱에서 |
| --- | --- |
| **그림 일과표**: 할 일을 그림 카드로 차례대로 보여 줌 | 오늘 할 일이 카드 줄로. 지금 할 것 하나만 크게 |
| **먼저 - 그다음**: 해야 될 일을 먼저, 좋아하는 일은 그 뒤 | TV · 탕목욕 놀이 같은 "즐거운 칸"은 앞의 일을 끝내야 열림 (부모가 켜고 끔) |
| **스스로 고르기**: 순서를 조금은 아이가 정하면 더 잘 함 | 부모가 "고정 / 몇 개는 아이가 순서 고르기" 선택 |
| **노력 칭찬**: "잘했어"보다 "스스로 가방을 정리했구나" | 토끼유 칭찬 말이 할 일마다 다름 (그 행동을 말해 줌) |
| **보상은 작게**: 큰 보상은 오히려 스스로 하려는 마음을 줄임 | 별 · 스티커 · 펫 정도. 돈 · 게임 시간 같은 큰 보상은 넣지 않음 |
| **화면 시간 늘리지 않기** | 앱은 "보고 끄는" 앱. 진행 중 화면은 짧게, 긴 영상 · 게임 없음 |

## 3. 아이 화면 흐름

```
앱 열기 → 토끼유 "어서 와요! 오늘 할 일은 5개예요" (목소리)
  → 오늘 할 일 카드 줄 (끝낸 것 ✓, 지금 할 것 크게, 잠긴 즐거운 칸 🔒)
  → 카드 누르기 → 할 일 화면 (큰 그림 + 목소리 안내, 필요하면 작은 단계 · 타이머)
  → "다 했어요!" → 별 + 칭찬 + 펫이 조금 자람
  → 다 하면: 축하 + 토끼유 한 컷 극장 (Let's Brush 극장 엔진) + 오늘 스티커
```

## 4. 할 일 종류 (사용자 예시로)

| 할 일 | 종류 | 앱에서 |
| --- | --- | --- |
| 학교 가방 정리 | 단계 있는 일 | 알림장 꺼내기 → 물통 · 도시락통 내놓기 → 내일 준비물. 단계마다 그림 |
| TV 보기 | **즐거운 칸 + 타이머** | 앞의 일을 다 해야 열림 (부모 설정). 30분 등 타이머 → 끝나면 토끼유 "TV 끄고 다음!" 소리 |
| 양치하기 | 다른 앱 연결 | Let's Brush 로 가기 단추. 같은 기기 · 같은 주소면 양치 기록을 읽어 자동 ✓ (가능한지 확인 필요) |
| 목욕 (이틀에 한 번) | **반복 규칙** | "이틀에 한 번" (마지막 목욕 날 기준) · "요일 지정" · "날마다" 중 고름 |
| 탕목욕하며 놀기 | 즐거운 칸 (목욕 날만) | 목욕 날에만 나타남. 욕조 놀이 아이디어 카드 (거품 수염 · 물총 · 장난감 배) |
| 그림 그리기 | 자유 시간 | 체크만 (그림 사진을 폰 안에 남기는 건 나중에) |
| 학습지 | 요일 지정 + **부모 확인** | 월 · 수 · 금처럼. 아이가 "다 했어요" → 부모가 곱셈 확인 뒤 도장 (부모 확인이 필요한 일만) |

- 할 일마다: 그림 · 이름 · 요일 규칙 · 타이머(없음 / N분) · 단계(없음 / 여러 개) · 부모 확인 필요 · 즐거운 칸 여부
- 기본 묶음 15~20개를 그림과 함께 미리 준비하고, 부모가 고르거나 이름만 바꿔 씀 (사진은 쓰지 않음, 개인정보)

## 5. 부모 화면

- 할 일 고르기 · 순서 · 요일 규칙 · 타이머 · 즐거운 칸 잠금 · 부모 확인
- 오늘 · 이번 주 한눈에 (무엇을 언제 했는지), 칭찬 도장
- 아이 여럿 (형제마다 다른 일과), 시간대 (방과 후 시작 시각)
- 알림: 웹앱은 정해진 시각에 폰 알림을 띄우기 어려움 (서버 푸시가 필요). **처음엔 알림 없이** "집에 오면 앱 열기"를 첫 습관으로. 필요하면 나중에 스토어 앱 알림

## 6. 공통 엔진에서 가져올 것 · 새로 만들 것

| 가져옴 (core) | 비고 |
| --- | --- |
| 저장 · 아이 여럿 · 부모 확인 · 번역 · 받는 언어팩 · 소리 · 목소리 · 익명 숫자 · 클럽(구독) · Play 결제 · 웹 막기 · 백업 · 자랑 카드 · 알 · 펫 엔진 · 펫 그림 252종 | 그대로 |
| 습관 엔진 (04-habit) | **고칠 것**: 지금은 습관이 하나(양치)라고 가정. 할 일 id 마다 기록하도록 넓힘 (Let's Brush 기록은 그대로 읽히게) |
| 극장 엔진 (지금 앱 16-theater.js) | **core 로 옮길 것**: 주인공 · 배경 · 소품을 앱이 넣게. 일과 앱은 토끼유가 주인공 |

| 새로 만듦 | 위치 |
| --- | --- |
| 토끼유 그림 (그림체 B, 표정 · 동작) | `characters/tokkiyou/js` (지금은 이름 · 설명만 있음) |
| 일과 엔진: 요일 · 이틀에 한 번 · 즐거운 칸 잠금 · 단계 · 타이머 | `core/js` (다음 앱 "배변 훈련 · 아침 준비"도 쓰게) |
| 할 일 그림 카드 20개 | 앱 |
| 아이 화면 · 부모 화면 | `apps/<새 앱>/` |

## 7. 만드는 순서 (세션 하나에 한 단계 정도)

1. **토끼유 디자인**: 시안 3개(그림체 B) → 사용자가 고름 → 기본 · 표정 6개 · 손 흔들기 · 박수. `characters/tokkiyou/`
2. **core 정리**: 습관 엔진을 여러 할 일로 · 극장 엔진을 core 로 · 새 앱 뼈대 (`docs/스튜디오_구조.md` 4장 순서) · 자동 점검을 두 앱 모두
3. **일과 엔진 + 아이 화면 + 부모 설정** (한국어 · 영어). 우리 집에서 바로 써 보기
4. **보상 · 축하 · 토끼유 한 컷 극장 · TV 타이머** 다듬기, 할 일 그림 카드
5. **아이 반응 보고 고치기** → 일본어 · 스토어

## 8. 시작 전에 사용자에게 물을 것

- 앱 이름: Let's Brush 처럼 아이가 지어 줄지
- 대상 나이 · 주로 쓸 기기 (아이 태블릿 / 부모 폰)
- 주인공: 토끼유 혼자 / 반짝이가 가끔 나옴
- TV 잠금: 할 일을 다 해야 열기 / 안내만 하고 막지는 않기
- 목욕 "이틀에 한 번" 기준 (마지막 목욕 날부터 / 홀짝 날짜)
- 학습지처럼 부모 확인이 꼭 필요한 일
- Let's Brush 와 기록 · 펫 · 별을 같이 쓸지 (같이 쓰려면 같은 주소에 올려야 됨)
- 무료 / 클럽(유료) 범위

## 9. 조심할 점

- 아이가 안 하고 "다 했어요"만 누르기 → 믿어 주되, 부모가 저녁에 한 번 보고 도장. 학습지 같은 일만 부모 확인
- 보상이 커지면 앱 없이는 안 하는 아이가 될 수 있음 → 별 · 스티커 정도, 점점 줄이는 설정(나중)
- 앱을 오래 보는 아이가 되지 않게 → 진행 화면은 짧게, 일을 할 때는 "화면 끄고 해요" 안내
