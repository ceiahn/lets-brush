# 명예의 전당 · 선물 이벤트 구상

문서 버전: v1.0 (2026-10-27, 앱 v0.46.0 기준)

유저가 어느 정도 쌓인 뒤에 만들 기능이에요. 지금은 구상만 해요. 바로 만들 것은 없고, **부모님 칭찬 도장 기록은 이미 폰 안에 쌓이고 있어요** (완료 화면에서 꾹 누르는 도장, `bj_log2`).

## 0. 원칙

1. **아이 개인정보는 모으지 않아요.** 이름 · 사진 · 생일 · 위치는 서버로 보내지 않아요.
2. **명예와 선물을 나눠요.** 명예는 기록 그대로 정하고 추첨하지 않아요. 추첨은 덤 선물에만 써요.
3. **조작은 서버가 직접 세서 막아요.** 실물 선물은 받을 사람만 부모님이 확인해요.
4. **아이에게 압박을 주지 않아요.** 꼴찌는 보이지 않게 하고, 선물 안내는 부모님 화면에만 둬요.

## 1. 하지 않기로 한 것: 양치 후 사진 인증

| 문제 | 설명 |
| --- | --- |
| 법 | 저장하지 않아도 아이 사진을 서버로 보내면 "수집"으로 볼 수 있어요 (미국 COPPA, 한국 만 14세 미만 보호자 동의). 얼굴로 누구인지 가리면 생체정보라서 더 엄격해요 |
| 스토어 | 데이터 보안 설문의 "수집 없음"이 사라지고, 가족 정책 심사가 까다로워져요 |
| 효과 | 사진으로는 양치를 했는지 알 수 없어요 (칫솔만 물고 찍으면 됨) |
| 비용 | 사진 확인 서버 · 보안 · 삭제 증명까지 생겨서 1인 개발로 감당하기 무거워요 |

대신 **실물 선물을 받을 소수만, 부모님이, 앱 밖(메일)에서** 짧은 영상으로 확인하고 확인 후 바로 지워요.

## 2. 명예의 전당 화면

```
🏆 명예의 전당
[우리나라] [전 세계]   ×   [이달] [역대]
 🏅 이달 개근 클럽 1,284명  (조건을 채운 친구 모두)
 1  🐧 용감한 펭귄 #4821   🇰🇷  이달 62회 · 도장 58
 2  🦊 반짝이는 여우 #0193  🇰🇷  이달 62회 · 도장 55
 …
 ⭐ 나: 🐰 졸린 토끼 #7752   이달 44회 · 상위 18% · 지난달보다 5회 더!
```

- **이달 (기간 기록)**: 그달 누적만 세고, 달이 바뀌면 새로 시작해요. 늦게 시작한 아이도 1등을 노릴 수 있어요.
- **역대 (상시 기록)**: 최장 연속 기록, 누적 양치 횟수
- **지난 명예**: "2026년 11월 · 대한민국 TOP 10 · 용감한 펭귄 #4821"처럼 한 번 오르면 지워지지 않아요.
- 순위표는 **상위 100명 + 내 위치**만 보여요. 내 위치는 등수 대신 "상위 18% · 나아진 점"으로 보여요.

### 나라별 · 전 세계
- 나라는 앱이 정한 나라(스토어 나라)를 쓰고, 기록 옆에 국기 하나만 보여요.
- 나라 순위와 전 세계 순위를 따로 계산해요. 둘 다 들면 배지도 둘이에요.

## 3. 순위 기준과 동점

"이달 양치한 날 수"만 세면 매일 한 아이가 모두 공동 1등이 돼요. 그래서 이렇게 해요.

1. **이달 개근 클럽**: 조건(예: 매일 아침 · 저녁 2회)을 채운 아이는 **전원** 명예의 전당에 올라가요.
2. **TOP 순위**는 아래 순서로 갈라요.
   1. 이달 양치 횟수 (하루 최대 2회 인정)
   2. 부모님 칭찬 도장 수
   3. 그달 최장 연속 기록
   4. 먼저 달성한 순서

## 4. 보상

| | 기준 | 보상 | 추첨 |
| --- | --- | --- | --- |
| 개근 클럽 | 조건 달성 전원 | 명예 등재 + 개근 배지 | 없음 |
| 나라 TOP 10 · 세계 TOP 100 | 기록 순위 | 명예 등재 + 앱 안 전용 보상 (왕관 옷 · 전용 펫 등) | 없음 |
| 나라 TOP 3 | 기록 순위 | 위 보상 + **실물 선물 (확정)**, 받기 전 부모님 확인 | 없음 |
| 노력상 | 조건 달성자 (예: 이달 40회 이상) | 실물 선물 | 있음 |

- 앱 안 보상은 배송 · 세금 · 개인정보가 필요 없고, 조작해도 얻는 게 작아요.
- 실물 선물은 **나라별로만** 줘요 (나라마다 배송 · 세금 규칙이 달라서, 행사를 여는 나라만 고름). 전 세계 순위는 명예만 줘요.

## 5. 개인정보 장치

| 장치 | 이유 |
| --- | --- |
| 별명은 단어 목록에서 자동으로 ("용감한" + "펭귄" + 번호), 직접 입력 없음 | 실명이 올라갈 일이 없고 욕설 검사가 필요 없음 |
| 아바타는 아이가 가진 펫 그림 | 사진 대신, 펫 모으는 동기 |
| 서버로 보내는 값: 익명 번호 · 별명 · 나라 · 양치 횟수 · 도장 수 | 이름 · 생일 · 위치 · 사진 없음 |
| 참여는 부모님이 켬 (설정, 부모 확인 뒤), 기본 꺼짐 | 아이 앱에서 서버로 보내는 것은 보호자 동의가 안전 |
| 끄면 서버 기록도 지움 | 삭제 요청 처리 |
| 형제는 아이별로 따로 참여 | 지금 아이별 기록 구조 그대로 |

- 참여를 켜면 데이터 보안 설문이 "앱 활동(기록 숫자) 수집, 익명"으로 바뀌어요. 개인정보처리방침에 한 단락을 더해요.
- 시작 전에 COPPA(익명 기기 번호 포함) · 한국 개인정보보호법 기준으로 전문가 확인을 한 번 받아요.

## 6. 조작 막기

- 양치를 마칠 때마다 서버에 "1회"를 보내고, **서버 시계로** 날짜를 적어요. 지난 날짜를 몰아서 채울 수 없어요.
- 하루 최대 2회 인정, 회당 최소 시간 같은 상식 규칙을 둬요.
- 인터넷이 없을 때는 모았다가 보내되, **24시간 안 것만** 인정해요.
- 부모님 칭찬 도장은 따로 셈해요. 도장이 많은 기록일수록 믿을 만해요.
- 실물 선물 받을 사람만 부모님 확인 (짧은 양치 영상을 메일로, 확인 후 삭제).

## 7. 기술 · 비용

- 서버: **Cloudflare Workers + D1** (R2와 같은 계정). 유저 수천 ~ 수만 명까지는 무료 범위일 가능성이 커요.
- 앱 쪽: 참여 켜기 · 끄기 설정, 양치 끝에 기록 보내기, 명예의 전당 화면, 별명 단어 목록(한 · 영 · 일), 개인정보처리방침
- 서버 쪽: 기록 받기, 순위 계산(나라 · 전 세계 × 이달 · 역대), 달 마감 · 지난 명예 저장, 삭제 요청

## 8. 선물 행사를 열 때

- **행사 규칙 공개**: 기간, 조건, 인원, 발표 방법. 구글 · 애플은 "이 행사는 구글/애플과 관계없음" 문구를 요구해요.
- **당첨자 정보**: 부모님 연락처 · 배송지만, 수집 동의를 받고 발송 후 정해진 기간에 지워요.
- **세금**: 한국에서는 경품이 일정 금액을 넘으면 기타소득세 원천징수 문제가 생겨요. 처음엔 소액 선물(스티커 · 굿즈 · 칫솔 세트)이 간단해요.
- 시작 전에 행사 규칙을 전문가에게 한 번 보여 줘요.

## 9. 순서

1. **지금**: 할 것 없음 (칭찬 도장 기록은 쌓이는 중)
2. **유저가 조금 쌓이면**: 해시태그 챌린지 (#반짝이양치). 부모님이 자랑 카드(v0.45.0)를 SNS에 올리면 그중에서 선물을 줘요. 앱 변경이 거의 없고 홍보도 돼요
3. **유저가 더 쌓이면**: 명예의 전당 (이 문서 2~7장)
4. **명예의 전당이 자리 잡으면**: 나라별 실물 선물 행사 (8장)

## 정한 것 · 남은 결정

- 정함: 나라별 + 전 세계 순위, 명예는 추첨 없이 기록 그대로, 개근 클럽 전원 등재 + TOP 순위
- 남음: 개근 기준(매일 1회 / 2회), 실물 선물 품목 · 금액, 처음 행사를 열 나라
