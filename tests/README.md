# 자동 점검

앱을 고친 뒤 망가진 곳이 없는지 한 번에 확인하는 도구예요. 앱에는 들어가지 않아요.

## GitHub에서 (따로 할 것 없음)

GitHub에 올리면 자동으로 돌아가요. 저장소의 **Actions** 탭에서 초록 ✓ 이면 통과, 빨간 ✗ 이면 문제가 있다는 뜻이에요. ✗ 를 누르면 무엇이 문제인지 보여요.

## 컴퓨터에서 직접 돌릴 때

```
cd tests
npm install
npx playwright install chromium
node run.js            # 전부 (약 2~3분)
node run.js --quick    # 글 · 파일만 (몇 초)
```

## 무엇을 보나요

| 점검 | 내용 |
| --- | --- |
| 금지 글자 | 공백을 지운 글에서 피하기로 한 글자 짝 |
| 문법 | `js/` 파일마다 `node --check` |
| 파일 목록 | `js/` 폴더, `index.html`의 `<script>` 줄, `sw.js`의 목록이 같은지 |
| 버전 | 여섯 곳의 버전이 같은지, 변경 기록에 그 버전 줄이 있는지 |
| 브라우저 | 한국어 · 영어 · 일본어로 화면을 돌아보고 양치를 끝까지: 오류, 영어 섞임, 언어팩 빠진 글 |
