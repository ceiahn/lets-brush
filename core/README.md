# core: 토끼유 스튜디오 공통 엔진

문서 버전: v1.3 (2026-10-27, Let's Brush v0.52.0: 24-stats · 받는 언어팩 packUpdate)

토끼유 스튜디오의 모든 앱이 같이 쓰는 코드와 리소스예요. 특정 앱(양치 등)의 내용은 넣지 않아요.

| 파일 | 하는 일 |
| --- | --- |
| `js/00-base.js` | `$` · `$$` · `pick` · 날짜 도우미 (`todayKey` · `dkey` · `slotOf` · `dayNum`) |
| `js/00-club.js` | 반짝이 클럽 엔진: 구독 상태 · `pro()` · 가격 글자 · 결제 흉내(`Billing`) · 스토어 앱 안인지(`inTWA`) |
| `js/01-store.js` | 폰 안 저장 (아이 여럿, 아이별 값) |
| `js/02-strings.js` | 공통 문구 (클럽 · 아이 여럿 · 부모 확인 · 백업 · 소리 · 자랑 카드 · 의견 · 웹 막기) 한 · 영 · 일 |
| `js/02-text.js` | 번역 엔진 `t()` · 받는 언어팩 · 글꼴 · `addText({ko, en})` (앱 파일이 자기 문구를 따로 더함, v0.51.0) · `packUpdate` (받는 언어팩 새 버전 · 처음 여는 기기 언어, v0.52.0) |
| `js/03-dates.js` | 나라 · 명절 날짜(`HOLIDAYS`, 음력 · 부활절 · 몇째 요일) · `activeEvent()` |
| `js/04-habit.js` | **습관 엔진**: `Habit.done()` · `Habit.stamp()` · 연속 기록 · 지킴이 방석 · 별 · 기록 |
| `js/07-helpers.js` | 화면 전환 · 대화창 · 알림 · 늦게 그리기 |
| `js/08-sound.js` | 소리 · 목소리 · 배경음악 · 녹음 |
| `js/09-effects.js` | 배경 효과 (눈 · 꽃잎 …) · 별 숫자(`setStars`) |
| `js/11-gate.js` | 부모 확인 (곱셈 문제) `parentGate()` |
| `js/13-pet-art.js` | 펫 그림 생성기 (252종 + 전설) |
| `js/14-eggs.js` | **알 · 펫 엔진**: 부화 · 성장 · 펫 선물 · 팀 · 이달의 친구 · 펫 옷 · 하트 · 재주 |
| `js/18-backup.js` | 기록 백업 · 불러오기 · 홈 화면 앱 등록 |
| `js/20-club.js` | 반짝이 클럽 화면 (요금제 안내 · 설정 칸 · 끝나기 전 알림 · 홈 화면 추가 안내) |
| `js/20-kids.js` | 아이 여럿 (고르기 · 바꾸기 · 추가 · 지우기) |
| `js/20-webgate.js` | 웹 막기 화면 |
| `js/22-play.js` | 구글 Play 결제 (스토어 앱 안) |
| `js/23-share.js` | 자랑 카드 · 의견 보내기 |
| `js/24-stats.js` | **익명 숫자** (v0.52.0): 부모님이 켠 경우만 이야기별 본 수 · 좋아요 수를 하루 한 번 (`Stats.add` · `Stats.flush`). 받는 서버 `tools/stats-worker` |
| `fonts/` | 주아 · 코스기 마루 (앱 안에 넣음) |

앱과의 약속(앱이 만들어 둘 이름 · HTML 조각)과 새 앱 만드는 순서: `docs/스튜디오_구조.md`

## 규칙
- 앱은 `../../core/js/…` 로 불러요. 파일 앞 번호 = 읽는 순서라서, 앱의 `index.html`에서 번호 순서대로 섞어 불러요.
- 앱이 만든 이름(`CONFIG` · `PACK_KO` · `EVENTS` · `renderPets()` …)을 약속대로 써요. 목록: `docs/스튜디오_구조.md` 2장
- 키즈앱 기준 기본값(부모 확인 · 광고 없음 · 아이 데이터 안 보내기)을 지켜요.
