# core: 토끼유 스튜디오 공통 엔진

문서 버전: v1.0 (2026-10-27, 모듈화 1단계 · Let's Brush v0.48.0)

토끼유 스튜디오의 모든 앱이 같이 쓰는 코드와 리소스예요. 특정 앱(양치 등)의 내용은 넣지 않아요.

| 파일 | 하는 일 |
| --- | --- |
| `js/01-store.js` | 폰 안 저장 (아이 여럿, 아이별 값) |
| `js/07-helpers.js` | 화면 전환 · 대화창 · 알림 · 늦게 그리기 |
| `js/08-sound.js` | 소리 · 목소리 · 배경음악 · 녹음 |
| `js/09-effects.js` | 배경 효과 (눈 · 꽃잎 …) · 별 |
| `js/13-pet-art.js` | 펫 그림 생성기 (252종 + 전설) |
| `js/18-backup.js` | 기록 백업 · 불러오기 · 홈 화면 앱 등록 |
| `js/22-play.js` | 구글 Play 결제 (스토어 앱 안) |
| `js/23-share.js` | 자랑 카드 · 의견 보내기 |
| `fonts/` | 주아 · 코스기 마루 (앱 안에 넣음) |

## 규칙
- 앱은 `../../core/js/…` 로 불러요. 파일 앞 번호 = 읽는 순서라서, 앱의 `index.html`에서 번호 순서대로 섞어 불러요.
- 아직 앱 쪽 값(`CONFIG`, `t()`, `streakDays()` 같은 것)을 그대로 쓰는 곳이 있어요. 2단계에서 앱이 넘겨주는 설정으로 바꿔요.
- 키즈앱 기준 기본값(부모 확인 · 광고 없음 · 아이 데이터 안 보내기)을 지켜요.
