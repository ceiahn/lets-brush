# 토끼유 (Tokkiyou) 🐰

문서 버전: v1.0 (2026-10-27)

토끼유 스튜디오의 마스코트예요. 토끼를 좋아하는 딸이 자기 이름과 토끼를 합쳐 지어 준 이름이에요.
영어 표기 Tokkiyou 의 "you" 도 그 이름에서 왔어요.

- 상태: **디자인 준비 중** (그림 코드 · 참고 그림 없음)
- 쓰일 곳 (계획): 스튜디오 로고 · 앱 시작 화면 "토끼유 스튜디오" · 부모님 안내(구독 · 설정) · 앱끼리 서로 소개 · 웹 막기 화면 · 자랑 카드 아래
- 그림이 생기면: `js/` 에 그림 코드(반짝이와 같은 그림체 B), `ref/` 에 참고 그림
- 주의: 공개 자료(스토어 · SNS · 이 저장소)에는 아이의 실명을 적지 않아요. "토끼를 좋아하는 딸이 지어 준 이름"처럼 써요
