# Let's Brush

3~7세 아이와 함께 쓰는 양치 웹앱이에요. 주인공 이빨 캐릭터 **반짝이**와 함께 2~3분 동안 구역을 차례로 닦고, 세균을 잡고, 펫을 키우고, 지도를 따라 모험해요.

앱 이름은 아이가 지어 줬어요.

- 버전: v0.52.5 (2026-10-28)
- 언어: 한국어 · English · 日本語(앱 안에서 받기)
- 화면: 세로 기준

## 들어 있는 것

v0.48.0 ~ v0.49.0 에 토끼유 스튜디오의 여러 앱이 같이 쓰는 구조로 나눴어요 (모듈화 1~4단계). 자세한 것: `docs/스튜디오_구조.md`


- **올릴 모습 만들기:** `node tools/build-site.js lets-brush` → `dist/` 에 앱을 맨 위로, 공통 파일을 그 아래로 모아요 (Cloudflare Pages 빌드 명령)
- **새 앱을 만들 때:** `docs/스튜디오_구조.md` 4장 순서대로. `core/` 는 그대로 불러 쓰고, 목록은 `node tools/sync-files.js <앱>`

## 써 보기

- **바로 열기:** `apps/lets-brush/index.html`을 브라우저로 열면 돼요 (맨 위 `index.html`도 그쪽으로 넘겨 줘요). 다만 휴대폰 파일 앱에서 바로 열면 `specials` 폴더의 영상을 못 읽을 수 있어요. 그럴 땐 부모님 설정의 "📥 스페셜 영상 넣기"로 영상을 앱 안에 넣어 주세요.
- **웹 주소로 열기 (추천):** 아래 "웹에 올리기"를 따라 하면 홈 화면 아이콘, 인터넷 없이 열기, 목소리 녹음까지 다 돼요.

## 웹에 올리기 (GitHub Pages)

1. 이 저장소의 **Settings → Pages**로 가요.
2. Branch는 `main`, 폴더는 `/ (root)`로 고르고 Save를 눌러요.
3. 1~2분 뒤 `https://(아이디).github.io/lets-brush/` 주소가 생겨요.
4. 폰 크롬에서 그 주소를 열고 메뉴(⋮) → "홈 화면에 추가"를 눌러요. 아이폰은 사파리 → 공유 → "홈 화면에 추가"예요.

새 버전을 올릴 때는 `index.html`과 `sw.js`를 같이 올려 주세요. v0.36.0부터는 `css` · `js` 폴더도 같이 올려 주세요 (처음 한 번은 폴더째, 그 뒤엔 바뀐 파일만). v0.33.0은 `fonts` 폴더와 `privacy.html` · `terms.html`도 처음 한 번 같이 올려 주세요. `sw.js` 안의 저장본 이름이 버전마다 바뀌어야 폰에 새 버전이 들어가요.

## 기록 옮기기

별 · 펫 · 연속 기록은 그 폰의 브라우저 안에만 저장돼요. 폰을 바꾸거나 여는 주소가 바뀌면 부모님 설정의 "💾 기록 백업"으로 파일을 저장한 뒤, 새 곳에서 "📂 기록 파일 불러오기"를 해 주세요.

## 테스트 모드

주소 끝에 붙여서 켜고 끌 수 있어요. 한 번 정하면 그 폰이 기억해서, 홈 화면 아이콘으로 열어도 그대로예요. 켜져 있으면 첫 화면 버전 글자 옆에 `· TEST`가 보여요.

- `index.html?test=1` 켜기 (별 100개 선물 · 개발자 메뉴) — v0.44.0 출시 잠금 뒤에는 `testParam` 을 잠깐 `true` 로 바꿔야 돼요 (apps/lets-brush/docs/출시_준비.md 3장)
- `index.html?test=0` 끄기 (출시 때와 같은 화면)
- `index.html?test=auto` 기억을 지우고 `index.html` 안의 `testMode` 값으로

`index.html` 안의 기본값은 꺼짐(`testMode: false`)이에요. 웹 주소를 다른 사람에게 보내도 테스트 기능이 나오지 않아요.

테스트 모드를 꺼도 이미 받은 테스트 별은 그대로 남아요.
