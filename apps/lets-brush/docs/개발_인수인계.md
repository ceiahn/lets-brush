# Let's Brush 개발 인수인계

새로 이어서 작업한다면 이 문서부터 읽을 것. v0.35.0 까지는 `index.html` 맨 위 주석에 있던 내용이에요 (v0.36.0 에서 파일을 나누면서 이리로 옮김).

```text
  ===========================================
  Let's Brush (렛츠 브러시) — 앱 이름은 아이가 지어 줌 (2026-10-26). 주인공 캐릭터 이름은 그대로 반짝이
  버전: v0.52.2  |  2026-10-27
  -------------------------------------------
  ★ 개발 안내 (다음 작업 세션 인수인계용) — 새로 이어서 작업한다면 이 부분부터 읽을 것
  -------------------------------------------
  [1] 무엇을 만드나
    · 3~7세 아이용 양치 타이머 웹앱. 빌드 없이 index.html 을 열면 동작 (서버 없음, 저장은 이 기기 localStorage)
      v0.36.0 부터 index.html(화면) · css/app.css(모양) · js/ 폴더(동작)로 나눔. 고친 파일만 올리면 됨
    · 주인공: 반짝이 (이빨 캐릭터, 직접 만든 오리지널. en: Sparkle / ja: キラリ). 남의 캐릭터 · 상표는 절대 쓰지 않음
    · 목표: 아이가 "내일 또 닦고 싶게" 만드는 것 (양치 2~3분이 지루하지 않게 + 다음 날이 기대되게)
    · 브랜드(만든 곳): 토끼유 스튜디오 / Tokkiyou Studio / トッキユ スタジオ (v0.44.1). 앱 이름은 Let's Brush 그대로
    · 만드는 분: 개발자가 아닌 한국인 부모. 나중에 앱으로 내고 수익화를 원함 → 설명은 쉬운 한국어로,
      코드 주석도 한국어로. resources.js 로 그림 · 아이템 · 음악을 코드 수정 없이 바꿀 수 있게 설계

  [2] 작업할 때 꼭 지킬 규칙 (사용자 요청)
    · 글 · 코드 모두 버전 관리: 고칠 때마다 버전 올리기 (위 "버전:" 줄 + 첫 화면 #ver 단추 글자 + 아래 변경 기록 한 줄)
      이전 버전은 versions/index_vX.Y.Z.html 로 보관 (v0.36.0 부터는 versions/vX.Y.Z/ 폴더째). 작은 수정 = 끝자리, 기능 묶음 = 가운데 자리
      버전을 올릴 때 같이 바꿀 곳: 이 문서 · index.html 머리 주석과 #ver 단추 · sw.js 의 CACHE · README.md
    · 금지 글자: 공백을 지웠을 때 '야' 바로 뒤에 ㅎ으로 시작하는 '하·해·했·합·할·한'이 붙으면 안 됨
      (성인 표현으로 오해될 수 있음 → "~해야 [ㅎ]는데" 대신 "~해야 되는데"처럼 ㅎ을 ㄷ으로 바꿔 씀)
      '아' 바로 뒤에 '다'가 붙는 것도 비속어로 걸리니 피할 것 (예: "돌-아-다니다" 같은 말은 다른 말로)
      → 검사는 공백을 다 지운 글에서 위 글자 짝을 찾는 방식 (이 안내문에도 일부러 붙여 쓰지 않았음)
      → 이 파일 · resources.example.js · 답장 글 모두 공백 지우고 검사한 뒤에 전달
    · 다른 프로젝트의 첨부 파일은 쓰지 않음
    · 무조건 맞장구치지 말고, 별로인 생각은 이유와 함께 솔직하게 말하기 (사용자가 직접 요청함)
    · 한국어 말투 (v0.24.1 사용자 결정): 아이에게 하는 말은 모두 존댓말(해요체). 이름은 "우리 {name}," 로 부르고
      "{name}아/야" + 존댓말처럼 섞지 않음. 극장에서 캐릭터끼리 노는 대사만 반말 가능
    · 화면은 세로 기준 (v0.25.1 사용자 결정): 가로 화면용 배치 작업은 하지 않음. 홈 화면 앱은 세로로 고정(manifest)
      (v0.25.0 에 넣은 첫 화면 · 완료 화면 가로 배치는 폰을 눕혔을 때 깨지지 않게 하는 정도로만 남겨 둠)

  [3] 게임 설계 원칙 (사용자와 합의한 것)
    · 하는 것: 매일 작은 보상 · 2~3일마다 새 펫 · 주마다 지도 섬(변신 옷 한 부분) · 달마다 새것(이달의 친구)
      변신 · 합체 연출 (아이들이 애니메이션에서 좋아하는 것), 동물 모으기, 큰 목표 저금(동물 집)
    · 하지 않는 것: 별로 뽑기 기계 · 현금 뽑기 · 광고 · 두 번째 화폐 · 등급/레벨 노가다 · 돈 내고 빨리 하기 ·
      합체하면서 펫이 없어지기 · 안 하면 줄어드는 하트(죄책감 장치)
    · 속도 조절: 펫 성장은 하루 perDay(2)번까지, 지도는 하루 3칸, 간식은 펫마다 하루 1번 → 몰아서 끝내지 못하게
    · 별 경제 (하루 2번 닦으면 하루 약 8개): 꾸미기 작은 물건 1~8개(값 유지) / 이번 주 물건 2~6개 /
      동물 집 30~150개 + 집 꾸미기 6~15개 (합계 약 510개 ≈ 두 달) / 간식 1개
  [4] 사업 모델 (얘기만 하고 아직 적용 안 함 — 적용 전 꼭 사용자와 다시 상의)
    · 제안: 무료 기본 + "가족 플러스"(구독 + 평생 이용권), 부모 확인 단계(어린이용 결제 보호), 광고 없음,
      나중에 치과와 협력(B2B). 결제는 "더 빨리"가 아니라 "더 넓게" (예: 새 변신 세트 · 동물 집 · 테마)
    · 사용자에게 물어본 3가지(가격대, 출시 나라, 구독/평생 중 선호)는 아직 답을 못 받음
```
