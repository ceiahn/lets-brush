## 3. 테스트 모드를 다시 켜고 싶을 때

출시 잠금 뒤에는 `?test=1` 이 안 먹어요. 내 폰에서 다시 시험할 때:

1. `js/00-config.js` 에서 `testParam: false` → `true` 로 잠깐 바꿔 올리기
2. 폰에서 `index.html?test=1` 로 열기
3. 시험이 끝나면 `?test=0` 으로 끄고, `testParam` 을 다시 `false` 로

- 자동 점검(`tests/`)은 잠금과 상관없이 테스트 모드로 돌아가요
- 예전에 테스트 모드였던 폰은 잠금 뒤 보통 모드로 돌아가요 (이미 받은 테스트 별은 그대로)
