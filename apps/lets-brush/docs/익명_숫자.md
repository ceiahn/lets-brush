# 익명 숫자: 아이들이 좋아하는 이야기 알아보기

문서 버전: v1.0 (2026-10-27, Let's Brush v0.52.0)

## 0. 한눈에

- 앱의 반짝이 극장이 끝날 때 ♡ 단추가 나와요. 아이가 누르면 그 폰에 "좋아요"가 쌓여요. 좋아요 한 이야기는 4번에 1번 다시 나와요. 아침 한 컷은 좋아요 한 개그가 더 잘 뽑혀요.
- **부모님이 설정에서 켠 경우만** 이야기마다 숫자 네 개를 하루에 한 번 토끼유 스튜디오 서버로 보내요.
  - 본 수 · 끝까지 본 수 · 건너뛴 수 · 좋아요 수
- 보내지 않는 것: 아이 이름 · 생일 · 기기 번호 · 광고 ID · 양치 기록 · 시각 · 어느 아이인지.
- 서버도 IP를 저장하지 않아요. 날짜 · 앱 · 언어 · 이야기마다 더한 숫자만 남아요.
- 서버 주소(`CONFIG.statsUrl`)를 비워 두면 설정 칸도 안 보이고 아무것도 보내지 않아요. **지금은 비어 있어요.**

## 1. 서버 만들기 (Cloudflare, 무료 한도 안)

Cloudflare 계정이 있으면 됩니다 (R2 · Pages 와 같은 계정). 컴퓨터에서 한 번만 하면 돼요.

```bash
npm install -g wrangler           # Cloudflare 명령 도구
wrangler login                    # 브라우저가 열리면 로그인
cd tools/stats-worker
wrangler d1 create tokkiyou-stats # → database_id = "…" 가 나옴
```

1. 나온 `database_id` 값을 `tools/stats-worker/wrangler.toml` 의 `여기에-d1-아이디` 자리에 붙여 넣어요.
2. 표를 만들고 올려요.

```bash
wrangler d1 execute tokkiyou-stats --remote --file=schema.sql
wrangler deploy                   # → https://tokkiyou-stats.<내이름>.workers.dev 주소가 나옴
```

3. 앱 설정에 그 주소를 넣어요. `apps/lets-brush/resources.js` 의 config 에 넣거나, `apps/lets-brush/js/00-config.js` 의 `statsUrl` 에 넣어요.

```js
statsUrl: 'https://tokkiyou-stats.<내이름>.workers.dev'
```

비용: Workers 무료 요금제는 하루 10만 번 요청, D1 무료 한도는 5GB 예요. 한 폰이 하루 한 번 보내니 사용자 수만 명까지도 0원이에요.

## 2. 숫자 보기

```bash
cd tools/stats-worker
# 지난 30일 좋아요가 많은 이야기 20개
wrangler d1 execute tokkiyou-stats --remote --command "SELECT kind, id, SUM(views) v, SUM(done) d, SUM(skips) s, SUM(likes) l, ROUND(100.0*SUM(likes)/MAX(SUM(views),1),1) AS like_pct FROM counts WHERE day >= date('now','-30 day') GROUP BY kind, id ORDER BY like_pct DESC LIMIT 20"
# 많이 건너뛰는 이야기 (고치거나 뺄 후보)
wrangler d1 execute tokkiyou-stats --remote --command "SELECT id, SUM(views) v, ROUND(100.0*SUM(skips)/MAX(SUM(views),1),1) AS skip_pct FROM counts WHERE kind='th' GROUP BY id HAVING v >= 30 ORDER BY skip_pct DESC LIMIT 20"
# 언어별
wrangler d1 execute tokkiyou-stats --remote --command "SELECT lang, SUM(views), SUM(likes) FROM counts GROUP BY lang"
```

읽는 법:
- **좋아요 비율(like_pct)** 이 높은 이야기 → 비슷한 이야기를 더 만들기. 스페셜 영상 후보.
- **건너뛴 비율(skip_pct)** 이 높은 이야기 → 너무 길거나 재미없는 것. 고치거나 빼기.
- 숫자가 적을 때(본 수 30번 아래)는 우연이 커서 판단하지 않기.

## 3. 출시 전에 할 것

- 개인정보처리방침에 이미 "보호자가 켠 경우에만 익명 숫자" 내용을 넣었어요 (privacy.html 4장).
- 구글 Play **데이터 보안** 양식: "앱 활동 → 앱 상호작용"을 **수집함 · 선택 사항 · 익명 · 앱 기능과 분석 목적**으로 적어요. 기기 ID나 개인 식별 정보는 "수집 안 함".
- 가족 정책(어린이 대상 앱): 광고 SDK · 분석 SDK 를 쓰지 않고 우리 서버로 숫자만 보내므로 괜찮아요. 다만 설정 칸 설명 글은 지우지 마세요 (보호자 안내).
