# 극장 캐릭터 음성 (AI 음성 파일)

문서 버전: v1.0 (2026-10-28, Let's Brush v0.52.5)

## 0. 한눈에

- 반짝이 극장 대사를 **캐릭터마다 다른 AI 목소리**로 미리 만들어 파일로 넣어요. Microsoft Azure 음성 서비스(무료 F0 요금제)를 써요.
- 앱은 대사 파일이 있으면 그 파일을 틀고, 없거나 못 받으면 지금처럼 **폰 목소리(TTS)** 로 읽어요. 그래서 일부만 만들어도 앱이 깨지지 않아요.
- 세 언어(한 · 영 · 일)는 언어마다 따로 목소리를 골라요. 세 언어에서 같은 목소리일 필요는 없어요.

## 1. 배역

| 역할 | 누구 | 이런 목소리 | 대사 수 (한국어) |
| --- | --- | --- | --- |
| nar | 해설 | 따뜻하고 차분한 동화 구연 | 약 280 |
| hero | 반짝이 | 밝은 아이, 성별 티 안 나게 | 약 255 |
| boss | 세균 · 대장 세균 | 장난꾸러기 악당 (무섭지 않게) | 약 130 + 세균 이름 대사 × 7종 |
| pet | 펫 | 작고 귀여운 목소리 하나 | 약 115 |
| pipi · mongi · coco · duri | 피피 · 몽이 · 코코 · 두리 | 꽃 요정 · 물방울 인어 · 아기 유니콘 · 아기 공룡 | 각 10~20 |
| prop | 조연 (부엉이 · 로봇 · 펭귄 · 달팽이 …) | 조연 목소리 하나 | 약 50 |

- 누가 말하는지는 앱이 극장을 틀 때 기록해요 (`SPEAKERS=1 node tests/theater-check.js` → `tools/voice/speakers.json`). 코드에서 짐작하지 않아요.
- 목소리 후보 · 고른 목소리 · 높낮이 · 빠르기: `tools/voice/cast.json`

## 2. 처음 한 번: Azure 준비 (15분)

1. https://portal.azure.com 가입 (카드 등록은 필요하지만 무료 한도 안에서는 청구 안 됨)
2. **Speech services** 리소스 만들기 → 가격 책정 계층 **Free F0** → 지역(예: Korea Central)
3. 리소스의 **키 및 엔드포인트**에서 키 1개와 지역 이름(예: `koreacentral`) 확인
4. Claude 작업 환경 설정 (세션 제목 줄의 클라우드 환경 메뉴 → Edit)
   - 비밀값(환경 변수): `AZURE_SPEECH_KEY` = 키, `AZURE_SPEECH_REGION` = 지역 이름
   - 네트워크 허용 목록: `<지역>.tts.speech.microsoft.com` (예: `koreacentral.tts.speech.microsoft.com`)
   - 키는 대화창에 붙이지 말 것. 새 세션부터 적용돼요
5. 무료 한도: 매달 일정 글자 수까지 무료 (가입할 때 확인). 우리 대사는 세 언어 합쳐 약 6만 자라 다시 만들기까지 해도 한도 안

## 3. 만들기 순서

```bash
SPEAKERS=1 node tests/theater-check.js      # 이야기를 고치거나 더했을 때: 누가 말하는지 다시 모음
node tools/voice.js voices ko-KR            # 쓸 수 있는 목소리 목록
node tools/voice.js sample ko               # 역할마다 후보 목소리로 대사 3줄 → lang-work/voice-samples/ko/
#   → 듣고 tools/voice/cast.json 의 "pick" 에 고른 목소리, 필요하면 pitch · rate 조절
node tools/voice.js script ko               # 만들 대사 수 · 글자 수 확인
node tools/voice.js build ko                # 전체 만들기 → apps/lets-brush/voice/ko/*.mp3 + voice/ko.json
node tools/voice.js build en && node tools/voice.js build ja
```

- 무료 요금제는 1분에 요청 수가 정해져 있어서 천천히 만들어요 (기본 1분에 18줄, `VOICE_RPM` 으로 바꿈). 한 언어 약 900줄이면 1시간 남짓
- 중간에 멈춰도 다시 돌리면 이미 만든 것은 건너뛰어요
- 대사 글 · 목소리 · 높낮이를 바꾸면 그 줄만 새로 만들어요 (파일 이름에 내용 표시가 있음)
- 어색한 줄: 글을 살짝 바꾸거나 (예: 띄어쓰기 · 문장부호), 그 역할의 rate · pitch 를 조절하고 build 다시

## 4. 이름이 들어가는 대사

| 자리 | 처리 |
| --- | --- |
| `{boss}` (대장 세균 이름) | 대장 세균 7종마다 파일을 따로 만듦 (키@세균id). 앱이 오늘의 세균에 맞는 파일을 틈 |
| `{pet}` (펫 이름) | 아이가 이름을 바꿀 수 있어서 미리 녹음 못 함 → 소리는 "친구" (영어 buddy · 일본어 ともだち), 말풍선 글자는 이름 그대로 |
| `{name}` · 화 번호 · 제목 · 여러 개 중 고르는 말 | 만들지 않음 → 폰 목소리 (제목 소개 · 끝인사 · 다음 화 예고) |

## 5. 앱 쪽

- `core/js/08-sound.js`: `Voice.play(키, 글)` 이 `voice/<언어>.json` 에 그 키가 있으면 파일을 틀고, 못 틀면 폰 목소리로 이어서 읽음. 끝날 때까지 기다리는 것은 폰 목소리와 같음
- `apps/lets-brush/js/16-theater.js`: 대사 키 그대로 (세균 이름 대사는 `키@세균id`) · 말하는 사람 기록 (`window.__thSay`)
- `sw.js`: 목록(json)은 인터넷 먼저, mp3 는 처음 틀 때 받아서 저장 (그 뒤엔 인터넷 없이도)
- 용량: 한 언어 약 10MB 예상. 앱 설치 때 다 받지 않고, 그 언어로 극장을 볼 때 한 줄씩 받음
- 파일을 다른 서버(R2 등)에 둘 때: `CONFIG.voiceBase` 에 주소

## 6. 라이선스 · 주의

- Azure 기본(신경망) 목소리로 만든 음성은 앱에 넣어 팔아도 되는 용도예요 (Microsoft 약관 기준, 계정 만들 때 한 번 더 확인).
- 실제 사람(연예인 · 성우)의 목소리를 흉내 내거나 복제하지 않아요.
