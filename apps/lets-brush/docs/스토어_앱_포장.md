## 0. 출시 구조: 스토어 앱 전용 (v0.47.0)

정한 것: **스토어 앱(TWA)만 쓰게 하고 웹으로는 못 쓰게.** TWA는 앱이 웹 주소를 열어 보여 주는 방식이라, 웹 주소는 남아 있되 브라우저로 열면 안내 화면만 나오게 해요. 코드를 고치면 심사 없이 바로 모든 폰에 반영되는 장점은 그대로예요.

### 웹 막기
- `apps/lets-brush/js/00-config.js` → `webBlock: true` 이면 브라우저로 연 사람에게는 "Let's Brush는 앱으로 만나요" 화면만 보여요 (스토어 링크 · 처리방침 · 약관 · 문의).
- 스토어 앱 안(`?src=twa`)과 테스트 모드는 그대로 열려요. 누가 주소에 `?src=twa`를 붙여 흉내 내도 Play 결제가 없어서 **무료 기능만** 써요 (체험 흉내도 안 됨).
- 약관(`terms.html`) · 처리방침(`privacy.html`)은 스토어 필수라 늘 열려 있어요.
- **개발 중에는 `false`**. 출시할 때 `webBlock: true` + `storeUrl`(스토어 앱 주소)을 넣고 버전을 올려요. `storeUrl`은 자랑 카드 주소로도 써요.

### 호스팅: GitHub Pages → Cloudflare Pages (무료, 추천)
지금 저장소는 **공개**예요 (GitHub Pages 무료는 공개 저장소만 됨). 그래서 코드 · docs(가격 전략 · 구상) · 커밋 기록을 누구나 볼 수 있어요. Cloudflare Pages는 **비공개 저장소도 무료**로 내보내고, 주소에 개인 이름이 안 나와요.

1. **지금 쓰는 기록 백업**: 지금 주소(GitHub Pages)로 쓰던 폰에서 설정 → 💾 기록 백업 (주소가 바뀌면 기록이 안 따라와요)
2. (선택, 추천) GitHub 저장소 이름을 `tokkiyou-apps`로 바꾸기 (Settings → General → Repository name). 여러 앱을 담는 저장소라서요. 예전 주소는 GitHub가 이어 줘요. Cloudflare 연결 **전에** 바꾸면 깔끔해요
3. Cloudflare (R2와 같은 계정) → **Workers & Pages → 만들기 → Pages → Git에 연결** → GitHub 허용 (`lets-brush` 저장소만 골라도 돼요)
4. 설정
   - 프로젝트 이름: 예 `letsbrush` → 주소 `https://letsbrush.pages.dev` (이미 있으면 다른 이름)
   - 프레임워크: 없음 · **빌드 명령: `node tools/build-site.js lets-brush`** · **출력 폴더: `dist`** (v0.48.0 모듈화 뒤. 앱이 dist 맨 위에 와요)
   - 이 스크립트는 앱에 필요한 파일만 모아요. docs · tests · android · tools는 안 올라가요.
5. 배포 → 새 주소가 열리는지 확인 → 백업 불러오기
6. GitHub 저장소 → Settings → Pages → 끄기, 그다음 Settings → General → Danger Zone → **Change visibility → Private**
   - 비공개로 바꿔도 Cloudflare Pages 자동 배포 · GitHub 자동 점검(Actions, 비공개는 월 2,000분 무료)은 그대로 돼요.
7. 새 주소에 맞게 바꾸기 (주소를 알려 주시면 제가 해요)
   - `apps/lets-brush/android/twa-manifest.json`: `host` · `startUrl`(`/index.html?src=twa`, 하위 폴더 없음) · 아이콘 · 매니페스트 주소
   - R2 CORS의 `AllowedOrigins`
   - `assetlinks.json`은 `apps/lets-brush/.well-known/assetlinks.json`에 두면 돼요 (빌드하면 주소 맨 위로 올라감). 별도 저장소가 필요 없어요.

**순서가 중요해요**: 스토어에 올리기 **전에** 옮기세요. 스토어 앱은 주소에 묶여 있고, 아이 기록도 주소에 묶여 있어서 출시 뒤에 옮기면 모든 사용자의 기록이 끊길 수 있어요. 도메인(예: tokkiyou.com)은 없어도 돼요. 나중에 사더라도 **출시 전에** 연결해야 같은 이유로 안전해요.

## 1. 계정과 비공개 테스트 규칙

- 2023년 11월 이후 만든 **개인** 개발자 계정은 정식 출시 전에 **테스터 12명 이상이 14일 연속** 참여한 비공개 테스트를 거쳐야 돼요. 도중에 12명 밑으로 떨어지면 다시 세는 경우가 있다고 하니, **15~20명**으로 여유 있게 시작하세요.
- **조직(사업자) 계정**은 이 규칙이 없어요. 개인사업자 등록 → D-U-N-S 번호(무료) → 조직 계정 순서예요. 스토어에 "토끼유 스튜디오"로 보이고, 유럽 판매자 정보에 집 주소 대신 사업장 주소를 쓸 수 있어요.
- 이 규칙은 외부 블로그 기준이라, 계정을 만들기 전에 Play Console 도움말에서 한 번 더 확인하세요.
- 테스터 의견은 앱 설정(부모님 칸)의 **"💌 의견 보내기"** 로 받으면 돼요. 메일에 앱 버전 · 폰 기종 · 언어 · 구독 상태가 자동으로 적혀요.

## 2. Bubblewrap으로 앱 만들기

PC(윈도우 · 맥)에 Node.js가 있으면 돼요. JDK · 안드로이드 SDK는 Bubblewrap이 처음 실행할 때 받아 줘요.

```bash
npm i -g @bubblewrap/cli
cd apps/lets-brush/android
bubblewrap init --manifest=https://ceiahn.github.io/lets-brush/manifest.json   # 묻는 값은 twa-manifest.json 과 같게
bubblewrap build                                                              # app-release-bundle.aab 가 나옴
```

- `twa-manifest.json`의 중요한 값
  - `packageId: com.tokkiyou.letsbrush`: 한 번 올리면 못 바꿔요. 바꿀 거면 첫 업로드 전에 바꾸고, `apps/lets-brush/js/00-config.js`의 `CONFIG.play.pkg`도 같이 바꾸세요.
  - `startUrl: /lets-brush/index.html?src=twa`: 앱 안인지 알아보는 표시예요. 이게 있어야 반짝이 클럽(구독)이 켜져요 (`CONFIG.subs.on:'play'`).
  - `features.playBilling.enabled: true`: 구글 Play 결제를 쓰게 해 줘요.
- **서명 키(`android.keystore`)와 비밀번호는 꼭 따로 보관하세요.** 잃어버리면 앱을 고칠 수 없어요. `.gitignore`가 저장소에 안 올라가게 막아 둬요.
- Play Console → 앱 만들기 → 테스트 → 비공개 테스트 → `.aab` 올리기.
- 앱 버전을 올릴 때마다 `appVersionCode`를 1씩 올리고, `appVersionName`은 앱 버전과 같게 맞춰요.

**웹 주소로 연 사람은?** `subs.on:'play'`라서 웹 주소(GitHub Pages)로 열면 지금처럼 모두 열려 있어요. 웹도 막으려면 나중에 `subs.on:true`로 바꾸면 돼요. 단, 웹에는 결제가 없으니 "앱에서 가입하세요" 안내를 따로 만들어야 돼요.

## 3. 웹 ↔ 앱 연결 (Digital Asset Links)

이 연결이 없으면 앱 위쪽에 주소창이 보이고, **결제도 안 돼요.**

1. Play Console → 설정 → **앱 무결성** → "앱 서명 키 인증서"의 **SHA-256** 값을 복사해요.
2. `apps/lets-brush/android/assetlinks.example.json`의 값 자리에 붙여 넣고 파일 이름을 `assetlinks.json`으로 해요.
3. 이 파일은 **주소 맨 위** `https://(주소)/.well-known/assetlinks.json`에 있어야 돼요.
   - **Cloudflare Pages(0장)로 옮기면**: `apps/lets-brush/.well-known/assetlinks.json`에 두면 끝이에요 (추천).
   - GitHub Pages 그대로면: 지금 주소 `ceiahn.github.io/lets-brush/`는 하위 폴더라, `ceiahn.github.io` 저장소를 하나 더 만들어 `.well-known/assetlinks.json` + 빈 `.nojekyll`을 올려야 돼요.
4. 확인: `https://(도메인)/.well-known/assetlinks.json`이 열리는지 보고, 앱을 열었을 때 주소창이 안 보이면 성공이에요.

## 4. 구글 Play 결제

### 상품 만들기 (Play Console → 수익 창출)

| 앱 안 이름 | 상품 ID (`CONFIG.play.skus`) | 종류 | 가격 · 혜택 |
| --- | --- | --- | --- |
| 월 구독 | `club_month` | 정기 결제, 1개월 | 나라별 가격: `docs/시장_언어_가격.md` 4장. 체험 혜택: 7일 무료 (새 사용자) |
| 연 구독 | `club_year` | 정기 결제, 1년 | 위와 같음 + 7일 무료 체험 |
| 평생 이용권 | `club_life` | 인앱 상품 (한 번 결제, **소모되지 않는 상품**) | 위 표의 life 가격 |

- 상품 ID를 바꾸면 `apps/lets-brush/js/00-config.js`의 `CONFIG.play.skus`도 같이 바꿔요.
- 앱은 **Play가 알려 준 가격(그 나라 돈)** 을 화면에 보여 줘요. 받기 전에는 `CONFIG.subs.price` 값으로 보여 줘요.
- 무료 체험 여부는 Play가 정해요. 처음 쓰는 구글 계정만 체험이 붙고, 결제 창에 그대로 보여요.

### 코드가 하는 일 (`core/js/22-play.js`)

- 앱을 열 때: 가격 받기 → `bj_playPrice`, 산 것 목록 → `bj_sub` (`active` · `life` · 끝났으면 `free`)
- 결제 버튼 → 부모 확인(곱셈) → Play 결제 창 → 끝나면 목록을 다시 읽어 확인
- "구매 복원" = 목록 다시 읽기, "구독 관리" = Play 구독 관리 화면
- 서버가 없어서 결제 확인은 폰 안에서만 해요. 작은 앱에서는 보통 이 정도로 시작하고, 불법 사용이 문제가 되면 그때 서버 확인을 더해요.

### 시험 (실제 돈 안 나감)

1. Play Console → 설정 → **라이선스 테스트**에 테스트할 구글 계정을 넣어요.
2. 비공개 테스트 트랙에 올린 앱을 그 계정 폰에 설치해요.
3. 확인할 것
   - [ ] 첫 화면 안내창 · 설정의 가격이 Play 가격(그 나라 돈)으로 나오는지
   - [ ] 연 구독(체험) · 월 구독 · 평생 이용권 결제 → 펫 · 지도 · 스페셜 영상이 열리는지
   - [ ] **3일 뒤에도 결제가 그대로인지.** Play는 "승인"되지 않은 결제를 3일 뒤 자동 환불해요. 크롬의 Digital Goods API 2.0은 결제를 자동으로 승인한다고 되어 있지만, 실제 기기에서 꼭 확인하세요. 환불되면 서버 승인이 필요해요.
   - [ ] 테스트 구독은 몇 분 단위로 갱신 · 끝남 → 끝난 뒤 앱을 다시 열면 무료로 돌아오는지 (받은 펫 · 옷은 그대로)
   - [ ] "구매 복원" · "구독 관리" 버튼

## 5. 스페셜 영상 서버 (Cloudflare R2 추천)

GitHub Pages는 사이트 1GB · 월 트래픽 한도가 있어서 영상이 늘면 곧 막혀요. R2는 내보내는 트래픽 요금이 없고 10GB까지 무료라서, 영상 100편 안팎은 사실상 0원이에요.

1. Cloudflare 가입 → R2 → 버킷 만들기 (예: `letsbrush-videos`) → 공개 주소(r2.dev 또는 자기 도메인 `videos.도메인`) 켜기
2. `ep001.mp4`, `ep002.mp4` … 와 `titles.txt`를 버킷 맨 위에 올려요. 파일 이름은 지금 `specials/` 규칙 그대로예요.
3. **CORS 허용**: 버킷 설정 → CORS 정책에 앱 주소를 넣어요 (미리 받기와 파일 확인에 필요해요)
   ```json
   [{ "AllowedOrigins": ["https://ceiahn.github.io"], "AllowedMethods": ["GET", "HEAD"], "AllowedHeaders": ["*"], "MaxAgeSeconds": 86400 }]
   ```
4. `apps/lets-brush/js/00-config.js` → `specialBase: 'https://(공개 주소)/'` → 버전 올리기 · 올리기
5. 확인: 설정 → 개발자 메뉴(테스트 모드)의 영상 확인, 또는 스페셜 화가 나오는 날 재생 · 비행기 모드에서 미리 받은 화 재생

## 6. 자랑 카드 · 구독 안내 시점

- **자랑 카드**: 완료 화면에서 연속 기록이 3 · 7 · 14 · 21 · 30 · 50 · 100 · 150 · 200 · 300 · 365일인 날 "📤 자랑하기" 단추가 나와요 (부모 확인 뒤). 설정에는 언제든 "자랑 카드 만들기"가 있어요. 카드 아래 주소는 `CONFIG.shareUrl`이에요. **스토어 주소가 생기면 여기에 넣으세요** (`https://play.google.com/store/apps/details?id=com.tokkiyou.letsbrush`).
- **구독 안내 시점**: `CONFIG.subs.askAfter` = 양치한 날이 이만큼 된 뒤 처음 안내해요. 지금은 `0`(처음 열 때)이에요. 아이가 재미를 느낀 뒤 부모님께 보여 주려면 `2`~`3`으로 바꾸세요. 비공개 테스트 동안 두 가지를 다 해 보고 정하면 좋아요.
